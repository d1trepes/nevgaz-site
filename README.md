# НевГаз — сайт (демо)

Демо-версия многостраничного сайта для **НевГаз** (Невинномысск) — газификация, отопление, водоснабжение и электрика частных домов под ключ. Этап 1: полностью проработанная главная (десктоп + мобилка).

**Для разработки через Claude: начни с [`CLAUDE.md`](./CLAUDE.md).**

## Быстрый старт
```bash
npm install
npm run assets   # скачать фото клиента из 2ГИС
npm run dev      # http://localhost:4321
```

## Что внутри
| Путь | Что |
|---|---|
| `CLAUDE.md` | Инструкция для Claude: порядок работы, правила, чек-лист |
| `docs/01-company-brief.md` | Бриф: услуги, контакты, цены, отзывы, что уточнить |
| `docs/02-homepage-spec.md` | ТЗ главной: 14 блоков с текстами и поведением, 3 концепции хиро |
| `docs/03-design-system.md` | Цвета, шрифты, компоненты, движение, правила логотипа |
| `docs/04-assets.md` | Каталог 16 фото клиента — что и куда |
| `docs/05-ai-media-prompts.md` | Промпты для недостающих фото и видео-хиро |
| `docs/06-mobile-and-performance.md` | Адаптив, Lighthouse-бюджет, доступность |
| `docs/07-sitemap.md` | Структура страниц |
| `public/brand/` | Логотип в SVG (горизонтальный, белый, с подписью, знак, favicon) |
| `src/data/company.json` | Все данные компании — единственный источник правды |
| `scripts/fetch-assets.mjs` | Загрузка фото из 2ГИС |
| `references/` | Референсы дизайна |
