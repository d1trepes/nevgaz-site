# 02 · ТЗ главной страницы

Главная многостраничного сайта (не лендинг). Каждый блок продаёт и ведёт вглубь — на страницу услуги, цен, работ, контактов (`07-sitemap.md`).
Все данные — только из `src/data/company.json`. Тексты ниже рабочие: смысл и длину держать, формулировки можно улучшать.

## Главный принцип
**Один идейный блок — хиро.** Он уже придуман и утверждён (дом с выключателями). **Все остальные блоки — спокойные, «дорогие», без фокусов**: строим их по референсам из `references/` (ref-01…05) — тёплый светлый фон, белые карточки, большие скругления, крупные фото с объектов, много воздуха. Никаких новых «вау-механик», схем, анимированных труб, счётчиков-барабанов. Задача остальных блоков — спокойно и убедительно продавать.
Перед каждым блоком перечитать «Арт-дирекшн», «Типографика текста», «Кнопки», «Сетка» в `CLAUDE.md`.

## Сетка и ритм страницы
- Контейнер до 1680px, 12 колонок, gap 24px, поля 16–28px. Всё выравнивается по колонкам; правые колонки текста прижаты к правому краю сетки.
- Заголовок секции (H2) — слева, крупно, в колонках 1–7; короткое пояснение и/или ссылка — справа в колонках 9–12, выровнено по низу заголовка (как в хиро). Это общий паттерн «шапки секции».
- Секции отделяются воздухом (`--section-y`), а не линиями и фонами. Тёмные (navy) блоки — максимум два на странице: «Наши работы» и финальная форма.
- Ритм: плотный блок → воздушный → плотный. Не все секции одной высоты.

## 3. Как мы работаем — стиль ref-04 (список с тонкими линиями + большое фото)
Шапка секции: H2 **Один подрядчик — от замера до тепла в доме**.
Слева (колонки 1–6) — список из 5 шагов, каждая строка: номер шага (это настоящая последовательность — номера уместны), название, одна строка пояснения, тонкая линия между строками; наведение подсвечивает строку и меняет фото справа.
1. Заявка — звоните или оставляете номер, перезваниваем.
2. Выезд и замер — мастер приезжает на объект, смотрит дом и сети.
3. Смета — подбираем оборудование под дом и бюджет, фиксируем цену.
4. Монтаж — своя бригада, без субподрядчиков.
5. Запуск — пусконаладка, сдача газовой службе, гарантия.
Справа (колонки 7–12) — большое фото со скруглением 22px, меняется по шагам: `ai/meter-check.jpg`, `photos/11-boiler-wall-2.jpg`, `ai/master-portrait.jpg`, `photos/08-gas-pipe-meter-facade.jpg`, `ai/flame-macro.jpg`.
