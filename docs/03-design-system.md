# 03 · Дизайн-система

Стиль взят с визитки клиента (`src/assets/brand-ref/story-business-card.jpg` после `npm run assets`): **тёмно-синий + оранжевый + белый**, плотный жирный кондесированный шрифт в логотипе. Настроение: «надёжный инженер» — чертёжная точность, тёплый свет дома, синее пламя газа. Не «нефтегаз-корпорация», а местная бригада, которой доверяют.

Токены уже заведены в `src/styles/tokens.css` — использовать только их.

## Цвета

| `--c-orange-600` | `#D2651A` | Hover/active кнопок |
| `--c-orange-glow` | `#FFB25E` | Свечения, градиенты, «тепло» |

| `--c-navy-900` | `#0A1A30` | Хиро, тёмные секции |

Соотношение: 60% светлые секции / 30% navy / 10% оранжевый. Оранжевый текст на белом — только крупный (≥ 24px bold) из-за контраста; для мелкого — `--c-orange-600`.

## Шрифты (Google Fonts / Fontsource, кириллица, `font-display: swap`, self-host через `@fontsource`)
- **Roboto Condensed** 700/800 — заголовки, цифры, кнопки, капс-надписи (родство с логотипом).
- **Manrope** 400/500/600 — основной текст.
Шкала (fluid clamp):
- H1 `clamp(40px, 6vw, 84px)` / lh 0.98 / ls -0.01em / uppercase не нужен
- H2 `clamp(30px, 4vw, 52px)` / lh 1.05
- H3 `clamp(20px, 2vw, 26px)` / lh 1.2
- Body 17px (M 16px) / lh 1.6; Small 14px
- Надзаголовков (eyebrow) нет — см. «Арт-дирекшн» в CLAUDE.md. Служебные подписи к фото и схемам: Roboto Condensed 600, 13px, uppercase, ls 0.08em, как маркировка в техдокументации.

## Сетка и отступы
- Контейнер 1280px + поля `clamp(16px, 4vw, 40px)`; 12 колонок, gap 24px; [M] 4 колонки, gap 16px.
- Вертикальный ритм секций: `clamp(72px, 10vw, 140px)`.
- Скругления: карточки 20px, фото 16px, кнопки 12px, чипы 999px.

## Компоненты
- **Кнопка primary**: оранжевая, белый текст Roboto Condensed 700 16px uppercase ls .04em, высота 56px (M 52px), иконка-стрелка/телефон справа, hover — темнее + стрелка сдвигается на 4px, внутренний блик.
- **Кнопка ghost**: 1.5px бордер (белый 30% на тёмном / ink 15% на светлом).
- **Карточка**: белая, бордер `--c-line`, тень `0 1px 2px rgb(10 26 48 / .06), 0 12px 32px -12px rgb(10 26 48 / .18)`.
- **Иконки**: минимум. Никаких иконок в цветных кружках над каждым пунктом. Если нужны — собственные, тонкой линией в стиле инженерного чертежа.
- **Фирменный язык**: материал их работы — трубы с отводами 90°, хомуты, жёлтая газовая маркировка, кирпич, чертёжные линии с размерами. Кольцо с разрывами из логотипа — только точечно (лоадер, маска одного фото), не размножать.

## Движение
- Появление блоков: fade + translateY(24px), 600ms, `cubic-bezier(.2,.7,.2,1)`, stagger 60ms. IntersectionObserver, без тяжёлых библиотек; GSAP+ScrollTrigger допускается только для хиро-схемы и таймлайна.
- Плавный скролл (Lenis) — опционально, отключать на тач-устройствах.
- `prefers-reduced-motion: reduce` — все анимации и частицы выключены, видео не автоплеится.

## Логотип (`public/brand/`)
- `logo-horizontal.svg` — основной, на светлом. `logo-horizontal-white.svg` — на тёмном. `logo-horizontal-navy.svg` — вариант.
- `logo-horizontal-tagline(-white).svg` — с подписью «Инженерные системы» (футер, OG).
- `logo-mark.svg`, `logo-mark-white.svg` — знак; `favicon.svg`.
- Текст в SVG переведён в кривые — шрифт не нужен. Минимальная высота горизонтального логотипа — 28px. Охранное поле — ½ высоты знака. Не перекрашивать знак, не обводить, не ставить на оранжевый фон.
