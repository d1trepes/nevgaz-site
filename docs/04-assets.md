# 04 · Ассеты

## Как получить фото
```bash
npm run assets
```
Скрипт `scripts/fetch-assets.mjs` качает оригиналы из 2ГИС в `src/assets/photos` и `src/assets/brand-ref`. Если что-то не скачалось — отключить VPN (2ГИС ограничивает зарубежные IP) и запустить снова, уже скачанное пропускается.
Фото подключать только через `astro:assets` `<Image>/<Picture>` — Astro сам сделает AVIF/WebP и `srcset`. Никаких оригиналов JPG напрямую в `<img>`.

## Чего не хватает → AI-генерация (`05-ai-media-prompts.md`)
1. Хиро: видео/фон (если вариант B) или иллюстрация дома-схемы (вариант A — рисуем SVG кодом, генерация не нужна).
2. Электромонтаж — своих фото нет.
3. Водоснабжение — красивый кадр бойлерной/разводки.
4. Мастер/бригада — до получения реальных фото.
5. Атмосферные: тёплый дом вечером, синее пламя конфорки крупно, руки мастера с ключом на газовом кране.
Сгенерированное кладём в `src/assets/ai/` с понятными именами; в `src/assets/ai/README.md` пишем, какой промпт и сервис.

## Правила обработки
- Единый вид серии: `aspect-ratio` в сетке фиксированный (4:5 или 4:3), `object-fit: cover`, одинаковая лёгкая коррекция.
- Горизонт у вертикальных снимков местами завален — в CSS не крутим, просто выбираем кадрирование `object-position`.
- Alt-тексты на русском, описательные («Газопровод с жёлтым ограждением у частного дома в Невинномысске»).
