# 06 · Мобильная версия, адаптив и производительность

## Брейкпоинты (mobile-first)
`360` базовый · `480` · `768` планшет · `1024` · `1280` десктоп · `1536` широкий. Проверять обязательно: 375×667 (iPhone SE), 390×844, 412×915, 768×1024, 1366×768, 1440×900, 1920×1080.

## Правила мобилки
- Первый экран 375×667: виден H1, подзаголовок (можно укоротить до 1 строки), кнопка «Вызвать мастера». Тексты не мельче 15px.
- Все горизонтальные ряды карточек (доверие, отзывы, работы) → `scroll-snap` свайп с peek 12–16% следующей карточки, без JS-слайдеров где можно.
- Тап-зоны ≥ 44×44, телефоны всегда `tel:`. Плавающая кнопка звонка после хиро.
- Мега-меню → шторка; аккордеоны вместо табов.
- Никакого горизонтального скролла страницы (`overflow-x: clip` на body не как костыль — искать причину).
- Безопасные зоны iOS: `env(safe-area-inset-bottom)` для плавающей кнопки.
- Ховер-эффекты оборачивать в `@media (hover: hover)`.

## Бюджет производительности (Lighthouse mobile ≥ 90 по всем 4 метрикам)
- LCP ≤ 2.5с, CLS ≤ 0.05, INP ≤ 200мс. JS на главной ≤ 80 КБ gz (без видео).
- LCP-элемент хиро: H1 или постер — постер `fetchpriority="high"`, остальное lazy.
- Шрифты self-host, subset `cyrillic` + `latin`, preload только Roboto Condensed 800.
- Видео: `preload="none"` + старт после `load`, не грузить при `navigator.connection.saveData` и при `prefers-reduced-motion`.
- Карта 2ГИС — только по клику/при приближении к экрану.
- Изображения: `astro:assets`, `widths=[480, 768, 1080, 1440]`, `sizes` честные.
- SVG-схема хиро — inline, анимации на `transform/opacity/stroke-dashoffset`, частицы — Canvas с паузой вне вьюпорта.

## Доступность
Контраст AA, видимый `:focus-visible` (оранжевое кольцо 3px), skip-link, `aria-label` у иконок-кнопок, `lang="ru"`, семантичные заголовки по порядку, формы с `label`.
