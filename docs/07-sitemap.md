# 07 · Структура многостраничника

На этом этапе полностью делаем только **главную**. Остальные страницы — заглушки с шапкой/футером, H1 и текстом «Страница в разработке», чтобы все ссылки главной работали.

```
/                         Главная  ← делаем сейчас
/uslugi/                  Все услуги
  /uslugi/gazifikaciya/   Газификация дома
  /uslugi/otoplenie/      Отопление и котельные
  /uslugi/vodosnabzhenie/ Водоснабжение и канализация
  /uslugi/elektromontazh/ Электромонтаж
  /uslugi/svarka-metallokonstrukcii/  Сварочные работы и металлоконструкции
/ceny/                    Цены
/raboty/                  Наши работы (галерея)
/o-kompanii/              О компании
/otzyvy/                  Отзывы
/kontakty/                Контакты
/politika/                Политика обработки персональных данных
/404                      Страница не найдена (с фирменным кольцом и кнопкой на главную)
```
Хлебные крошки на внутренних. Меню и футер генерируются из одного массива `src/data/nav.ts`.
