# 09 · План работы в Claude Code (3 чата)

## Чат 1 — собрать главную (десктоп)
1. Прочитать `CLAUDE.md`, `docs/01…09`, `references/README.md` и картинки в `references/`.
2. `npm install`, `npm run assets` (докачать фото из 2ГИС; при ошибке — сказать про VPN).
3. Каркас: `Base.astro` (шрифты уже подключены), `Header.astro` (sticky, выпадающее меню услуг), `Footer.astro`, `LeadModal.astro`, заглушки всех страниц из `07-sitemap.md`.
4. **Хиро** — перенести `prototypes/hero-variants.html` в `src/components/home/Hero.astro` один в один: разметка, CSS, скрипт выключателей, логика слоёв. Картинки — из `src/assets/hero/` через `astro:assets`. Не «улучшать».
5. Блоки 2–12 по `docs/02-homepage-spec.md`, в порядке спеки, каждый — отдельный компонент в `src/components/home/`. Стиль — референсы ref-01…05, спокойно, без новых механик.
6. После каждых 2–3 блоков: `npm run build`, скриншот 1440×900 (Playwright) и короткий отчёт мне.
7. В конце: чек-лист десктопа ниже, коммит, пуш в `main` (деплой на Pages пойдёт сам).

## Чат 2 — правки
Я присылаю скриншоты и замечания. Правило: правим точечно, не переписываем блоки целиком, не трогаем хиро без прямой просьбы. После правок — сборка, скриншот, пуш.

## Чат 3 — мобилка
По `docs/06-mobile-and-performance.md`: поблочно, от шапки к футеру, на 375 / 390 / 768. Потом Lighthouse mobile, фиксы, пуш.

## Чек-лист десктопа (чат 1)
- [ ] Хиро целиком в первом экране на 1366×768, 1440×900, 1920×1080, выключатели работают в любых комбинациях
- [ ] Все блоки по 12-колоночной сетке; шапки секций одинакового паттерна
- [ ] Ни одного надзаголовка, иконки в кружке, выдуманной цифры, повторяющейся надписи на кнопках
- [ ] Смысловые переносы во всех H1/H2, неразрывные пробелы после предлогов
- [ ] Все кнопки — оранжевые с белым кружком-стрелкой
- [ ] Все ссылки меню и карточек ведут на существующие страницы
- [ ] `npm run build` без ошибок и предупреждений
