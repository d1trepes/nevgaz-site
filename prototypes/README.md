# Прототипы

`hero-variants.html` — согласовываемый прототип первого экрана: два варианта хиро («Труба» и «Разрез дома») с навигацией, десктоп и мобилка. Внизу переключатель вариантов (это инструмент ревью, на сайт не переносится).
Картинки внутри вшиты в base64 — в Astro-версии брать их из `src/assets/ai` и `src/assets/photos` через `astro:assets`.
После выбора варианта перенести разметку/стили/скрипт в `src/components/home/Hero.astro` (+ `HeroHouse.astro` для разреза).
